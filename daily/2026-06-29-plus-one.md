# 2026-06-29 - Plus One

## Problem

- Number: 66
- Title: Plus One
- Link: https://leetcode.com/problems/plus-one/
- Difficulty: Easy
- Language: Java
- Attempt type: reviewed with assistance

## Main Idea

題目給我們一個陣列，每個位置是一個數字，例如：

```text
[1, 2, 3] 代表 123
```

要做的事是把整個數字加一，所以答案是：

```text
[1, 2, 4]
```

加一一定從最右邊的個位數開始看：

- 如果最右邊不是 `9`，直接加一就結束。
- 如果是 `9`，加一會變成 `10`，這一位要變成 `0`，並且把進位交給左邊。
- 如果全部都是 `9`，例如 `[9, 9, 9]`，答案會多一位，變成 `[1, 0, 0, 0]`。

## Core Code

```java
for (int i = digits.length - 1; i >= 0; i--) {
    if (digits[i] < 9) {
        digits[i]++;
        return digits;
    }

    digits[i] = 0;
}

int[] result = new int[digits.length + 1];
result[0] = 1;
return result;
```

## Complexity

- Time: O(n)，最壞情況要從最後一位一路看到第一位，例如 `[9, 9, 9]`。
- Space: O(1)，大多數情況直接改原本的陣列；如果全部都是 `9`，才需要建立一個新陣列。

## Mistakes to Avoid

- 不要只處理最後一位，因為 `[1, 2, 9]` 加一後應該是 `[1, 3, 0]`。
- 遇到 `9` 時要把它改成 `0`，不是保留 `9`。
- 全部都是 `9` 時，答案長度會增加一格，不能只回傳原本長度的陣列。
- `return digits` 要放在成功加一且沒有進位的時候，否則會太早結束。
